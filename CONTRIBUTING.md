# Contributing

Thank you for your interest in contributing to this project! This guide will help you get started with development.

## Prerequisites

- **Node.js** (LTS recommended; see `@types/node` version in `package.json` for target version)
- **npm** (comes with Node.js)
- A running **PostgreSQL** database instance

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

This installs all required dependencies listed in `package.json`.

### 2. Configure Environment Variables

Create a `.env` file at the repository root with the following variables:

```
DATABASE_URL=postgresql://<user>:<password>@<host>:<port>/<dbname>
JWT_SECRET=<your-secret-key>
NODE_ENV=development
```

### 3. Set Up the Database

Generate the Prisma client:

```bash
npx prisma generate
```

Apply database migrations:

```bash
npx prisma migrate deploy
```

(Optional) Seed the database with sample data:

```bash
npx prisma db seed
```

## Development

### Run the Development Server

```bash
npm start
```

This runs `nx serve`, which builds and starts the Express server in development mode.

### Run Tests

```bash
npm test
```

This runs `nx test`, which executes the Jest test suite.

## Building for Production

```bash
npm run build
```

This compiles the TypeScript source code and outputs to the `dist/` directory.

## Additional Commands

- **Lint code**: `npx nx lint`
- **Build Docker image**: `npx nx docker-build`

## Project Structure

- `src/` — Application source code (TypeScript)
- `e2e/` — End-to-end tests
- `src/prisma/` — Database schema and migrations
- `dist/` — Compiled output (generated by build)
